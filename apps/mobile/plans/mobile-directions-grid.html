Vitals Remote · mobile · round 2

Three directions. Pick one.

Same in all threeTrue black, white text, yellow accent, orange and red for trouble. Instrument Serif, Geist, Geist Mono.
One code pathEvery screen and sheet is one React Native component for iOS and Android. No per-platform forks.
Sheets@gorhom/bottom-sheet, the same setup Lumo uses: 300 ms open, 200 ms close, drag to dismiss, Android back closes it. Tap "Play" on any sheet phone.
Mobile owns its UIThe phone app gets its own components, no longer shared with the web client. The Mac app stays SwiftUI, untouched.
Hold only to destroyShut down, Restart, Log out, Quit, Force quit and Unpair need a hold. Everything else is a tap. Try holding the red buttons.
